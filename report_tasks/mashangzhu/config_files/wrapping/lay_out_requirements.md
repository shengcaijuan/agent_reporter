## 第一章节：薪资绩效分析
1. 卡片展示排名数据，并换行脚注排名层级，采用省区排名；
2. 表格展示绩效分数和未达标绩效项目情况，表头为"考核项目、完成情况、关键详情"，完成情况列展示未达百绩效项目达成率（绩效总分展示分数），关键详情列阐述绩效项目月均分数、全年总扣分、绩效项目水平（绩效总分陈述未达百项目）；
3. 绩效总分要括号注释“不含其他奖惩”；
4. 考核项目列仅陈述绩效项目指标名称，不需要增加其他备注或尾缀内容；
5. 关键详情列的文字表述不用加黑加粗；

## 第二章节：销售动能分析
1. 如果收入同期数为0，则同比变化记为100%，需要括号注释“同期收入为0”；
2. 正向指标和风险指标竖向排布，并且每个部分按照产品、客户、渠道几个方面陈述指标情况；

## 第三章节：毛利率与产品结构
1. 排名卡片中括号标注毛利率、高值品收入占比、艺术漆收入占比；
2. 价格变动和结构变化变化，采用表格形式展示，表格的表头为指标和详情，指标为价格变动和结构变化，详情为价格变动和产品收入占比变化的情况；
3. 表格不要有空余表格，确保表格内容完整；
4. 不要仅展示数据，用简洁的语言稍加叙述，保持语言精简；
5. 价格变动需后缀“（同比，折后返利前均价）”，结构变化需后缀“（同比）”；
